# NSLGbeta

Windows 本地离线测试启动器。当前为已在本机测试的版本。

双击 NSLGbeta.exe 并接受管理员提示。依赖原游戏安装、Node、REA/Frida；不是独立游戏安装包。当前路径固定为本机 outputs/offline-login，仓库副本不能移动后直接运行，需调整脚本内路径并重新编译 LuaJIT 字节码。

包含离线角色入口、GM 切池、武将与战法混合抽取、库存持久化。基础概率金8%、紫30%、蓝62%，各档武将与战法各半；每池连续19抽无金，第20抽必金，出金重置。保底提高长期出金率。缺少六类条目的池拒绝抽取。

已保留原招募动画入口，完整动画结束尚未验证。GM 点击改用鼠标位置检测；真实点击未完成自动化验证。不是完整离线玩法实现。

不包含个人存档、测试日志、截图、游戏安装文件和批量提取配置。original-patcher.ljbc 是离线启动所需的原客户端 Lua 更新入口。仅供本项目内部测试。
